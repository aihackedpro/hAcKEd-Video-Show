## ใช้งานอย่างไร

1. ติดตั้งโปรแกรม หรือแตก Portable ZIP ให้ครบชุด
2. กด **เพิ่มไฟล์** เพื่อเพิ่มวิดีโอ/เสียงในเครื่อง หรือ **เพิ่มลิงก์** เพื่อใส่ URL ที่เปิดดูได้แบบสาธารณะ
3. ตรวจภาพด้วย **ดูตัวอย่าง** แล้วกด **เล่นขึ้นจอ** หรือ **ฉายรายการตัวอย่างนี้**
4. เลือกจอฉายเมื่อต้องการส่งภาพออกจอภายนอก
5. บันทึกรายการเป็นโปรไฟล์เพื่อกลับมาเปิดใช้ภายหลัง

รองรับเมนูภาษาไทย/อังกฤษ เพิ่มรายการซ้ำ ลากเรียงลำดับ เปลี่ยนชื่อ ค้นหา เล่นวนซ้ำ และบันทึกรายการ/การตั้งค่าอัตโนมัติ

## ข้อควรรู้

- ทดสอบ YouTube, YouTube Live, Facebook Video และ Reels แล้ว ส่วน Facebook Live มีการรองรับแต่ยังไม่ได้ทดสอบกับรายการสดจริง
- ลิงก์ต้องเปิดให้เข้าถึงสตรีมได้ ไม่รองรับ private/login-required/DRM; เว็บไซต์อาจเปลี่ยนระบบจนต้องอัปเดตโปรแกรม
- Live ต้องรับบัฟเฟอร์จากต้นทาง และไม่มี seek/วนย้อนหลังเหมือนวิดีโอที่บันทึกไว้
- ชุดโปรแกรมมี runtime และตัวถอดรหัสแล้ว ไม่ต้องติดตั้ง Python แยก
- EXE ยังไม่ได้ลงนาม อาจมี SmartScreen แจ้งเตือน ไม่แนะนำให้ปิด antivirus หรือเพิ่มข้อยกเว้น
- ชุด 1.1.1 ผ่าน build, 54 automated tests และตรวจ ZIP/SHA-256; Microsoft Defender สแกนแล้วไม่พบภัยคุกคาม ณ วันที่ตรวจ ไม่ใช่การรับประกันผลจาก antivirus ทุกยี่ห้อ
